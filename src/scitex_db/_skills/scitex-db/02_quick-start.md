# Quick Start

The maintained example is [11_quick-start.md](11_quick-start.md). It uses a
required SQLite context manager, verifies rows and array round trips, and
previews duplicates only in its own temporary database. The historical
examples on this page have been replaced to avoid conflicting instructions.

See [03_python-api.md](03_python-api.md) for the public surface,
[15_maintenance.md](15_maintenance.md) for health-provider and repair limits,
and [16_sqlite-to-postgres.md](16_sqlite-to-postgres.md) before a backend port.
